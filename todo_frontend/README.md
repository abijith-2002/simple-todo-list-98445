# Ocean Professional Todo Frontend (React)

A simple Todo List application with a clean, modern UI. Users can add, update, delete, toggle complete, and filter tasks (All/Active/Completed). Frontend-only.

## Quick Start
- Install: `npm install`
- Run dev server: `npm start`
- Build: `npm run build`

## Features
- Add, edit (inline via form), delete, toggle complete
- Filters: All / Active / Completed
- Clear completed action
- LocalStorage persistence (browser only)
- Light/Dark theme toggle
- Ocean Professional styling (blue & amber accents, rounded corners, subtle gradients and shadows)

## Design
- Centered column layout
- Subtle gradient backdrop, soft elevation, and smooth transitions
- Primary: `#2563EB` (Blue), Amber accent: `#F59E0B`

You can adjust theme variables in `src/App.css`.

## Notes
- No backend or environment variables required at this stage.
- Tests remain from CRA template and can be adapted as needed.
